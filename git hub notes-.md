git hub notes-

* Git hub is not the same as git
* git is the coffee whilst GitHub is the coffee shop
* git is a powerful tool that tracks changes in any files
* it lets you keep multiple versions of a single file if any changes are made
* mostly used in coding projects
* its called version controlled system
* made by linus Torvalds same as Linux
* git runs locally on your computer, GitHub is used to merge multiple version of a code, used as a central online server.
* GitLab and bitbucket can be used
* git is divided into two parts local and remote
* where you work is called working directory
* \---> staging (my changes are ready to move to the next step) ---> local repo ( tempo area to save your version of file) ---> commit ( uploaded to the cloud)
* repository - every version and every change of the file is stored, changes, history and commit.
* git add --all / -a adds every changes to staging area
git add. adds only changes in current directory 

&#x09;git add \* adds only new or modified files not deleted ones stages all visible changes except deletion

* git reset to to return to unstaged stage 
* git reset --hard to return changes and the files to unstaged stage
* git rm --force no matter what delete files
* git rm--cached delete from staging area
* git rm -r to delete a directory 
* branching is used to try new developments, then committing it and then merging it using GitHub
* allows to review test and manage tests
* now we want to push the commit from local repository to the remote repository 
* fetch bringing remote changes to local 
* pull merging the remote changes whilst fetching to local
* restore , lets us restore to last commit version
* stash - used to temporarily switch branches, or else during checkout you cant switch unless the changes are committed
* apply lets you take the changes from the stashes without removing them from the stash 
* pop removes them completely
* revert fixes an old mistake without removing it 
* rebase used to merge a change on the main branch to your current working branch
* the new branch just shifts postions to a new commit on the main branch
